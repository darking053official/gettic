Dokümantasyon

gettic.js API referansı. ID'leri webhook entegrasyonunda kullan.

🚀 Hızlı Başlangıç

gettic.js'i yükle ve ilk botunu oluştur.

// Kurulum

npm install gettic.js

// Minimal Bot

const { Client } = require('gettic.js');
const bot = new Client({ token: 'BOT_TOKEN', username: 'BenimBot', prefix: '/' });
bot.on('ready', () => bot.send('genel', 'Merhaba! 🤖'));
bot.command('ping', ctx => ctx.reply(`🏓 ${bot.ping}ms`));
bot.connect();

🆔 ID Sistemi

Her varlığın benzersiz bir MongoDB ObjectId'si vardır.

// ID'leri Nerede Bulursun?

Mesaj, kanal ve sunucu ID'lerine erişmek için:

  • Mesaj üzerine gelince araç çubuğunda 🆔 butonuna tıkla
  • Kanalın üstündeki topbar'da kanal ID rozetine tıkla
  • Sunucu ayarlarında sunucu ID görünür
  • Bot panelinde bot token, webhook panelinde URL + ID'ler listelenir

// Webhook'ta ID Kullanımı

// Bot mesaj gönderince dönen yanıtta messageId bulunur
POST /api/bot/send
{ "token": "bot_xxx", "room": "genel", "message": "Merhaba" }

// Yanıt:
{ "success": true, "messageId": "6623a1f2...", "channelId": "6620b3c1...", "serverId": "660fa..." }

// Webhook ile de aynısı:
POST /api/webhook/TOKEN
{ "content": "Merhaba" }
// Yanıt: { "success": true, "messageId": "...", "channelId": "..." }

💡 Örnekler

// ID'yi kullanarak mesaj sil

// Bot tarafında:
bot.on('message', async (msg) => {
    // msg._id = mesaj ID
    if (msg.content === '!sil') {
        await fetch(`/api/messages/${msg._id}`, {
            method: 'DELETE',
            headers: { Authorization: 'Bearer ' + botToken }
        });
    }
});

// Webhook ile ID takibi

const wh = new WebhookClient('WEBHOOK_URL');
const result = await wh.send('Merhaba!');

console.log(result.messageId);  // 6623a1f2b8e4c...
console.log(result.channelId);  // 6620b3c1d9f2a...

// Sonradan bu mesajı bul:
const res = await fetch(`/api/channels/${result.channelId}/messages`);

// CI/CD Deploy

const wh = new WebhookClient(process.env.WEBHOOK_URL);
const res = await wh.sendEmbed({
    title: '✅ Deploy Başarılı',
    description: 'main → production',
    fields: [{ name: 'Commit', value: process.env.SHA.slice(0,7) }]
});
console.log('Mesaj ID:', res.messageId);
